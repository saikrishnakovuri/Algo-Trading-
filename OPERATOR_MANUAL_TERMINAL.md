# 📖 OPERATOR MANUAL: TradeAlert Terminal

## Navigation
- **Dashboard:** High-level health and quick controls.
- **Live P&L:** Real-time money tracking.
- **Configs:** YAML editor for bot parameters.
- **System Settings:** View-only v3_utils constants.
- **RiskGuard:** Reset daily limits here.
- **Logs:** Real-time log streaming from the bot.

## Shortcuts
- **Ctrl+S:** Save Config (in Configs tab).
- **Esc:** Close any open modal.

## Troubleshooting
- If logs stop moving, check if the bot process is running in System Status.
- If UI is blank, restart the backend server.

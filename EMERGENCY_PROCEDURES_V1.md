# 🚨 EMERGENCY PROCEDURES V1

## Scenario A: Internet Drop
- **Action:** Manual stop on phone if possible. Once internet returns, verify positions in dashboard.

## Scenario B: Exchange Error (999)
- **Action:** Press EMERGENCY KILL SWITCH. All orders will be attempted to be cancelled.

## Scenario C: Bot Crash (Loop)
- **Action:** Stop the backend server immediately. Run `emergency_reset.py`.

## Scenario D: Daily Loss Limit Hit
- **Action:** RiskGuard will auto-stop the bot. Do NOT restart manually without reviewing the loss.

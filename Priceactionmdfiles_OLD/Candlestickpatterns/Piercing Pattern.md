# Piercing Pattern — Complete Bullish Price Action Trading Guide

---

# 1. Introduction

The Piercing Pattern is one of the most important two-candle bullish reversal patterns in technical analysis and price action trading.

It signals:
- Seller exhaustion
- Buyer recovery
- Potential bullish reversal

The pattern forms when:
- A strong bearish candle is followed by a bullish candle
- The bullish candle closes deep into the bearish candle body

The Piercing Pattern is widely used in:
- Stocks
- Forex
- Crypto
- Futures
- Options
- Indices (NIFTY/BANKNIFTY)

It is considered:
# A strong early bullish reversal warning signal.

---

# 2. Structure of the Pattern

The pattern contains two candles:

1. Strong bearish candle
2. Strong bullish recovery candle

---

# Visual Structure

First Candle:
  __________
 |          |
 |          |
 |__________|

Second Candle:
        __________
       |          |
       |          |
       |__________|

Second candle:
- Opens below previous close
- Closes above midpoint of bearish candle

---

# Key Characteristics

## First Candle
Large bearish candle

Represents:
- Strong seller dominance

---

## Second Candle
Bullish candle

Should:
- Open lower
- Reverse upward strongly
- Close above midpoint of bearish candle

---

# Important Rule

The bullish candle does NOT need to fully engulf prior candle body.

That difference separates it from:
# Bullish Engulfing Pattern

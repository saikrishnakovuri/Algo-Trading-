# Dark Cloud Cover Pattern — Complete Bearish Price Action Trading Guide

---

# 1. Introduction

The Dark Cloud Cover Pattern is one of the most important two-candle bearish reversal patterns in technical analysis and price action trading.

It signals:
- Buyer exhaustion
- Seller recovery
- Potential bearish reversal

The pattern forms when:
- A strong bullish candle is followed by a bearish candle
- The bearish candle closes deep into the bullish candle body

The Dark Cloud Cover Pattern is widely used in:
- Stocks
- Forex
- Crypto
- Futures
- Options
- Indices (NIFTY/BANKNIFTY)

It is considered:
# A strong early bearish reversal warning signal.

---

# 2. Structure of the Pattern

The pattern contains two candles:

1. Strong bullish candle
2. Strong bearish recovery candle

---

# Visual Structure

First Candle:
       ____________
      |            |
      |            |
      |____________|

Second Candle:
   __________
  |          |
  |          |
  |__________|

Second candle:
- Opens above previous close
- Closes below midpoint of bullish candle

---

# Key Characteristics

## First Candle
Large bullish candle

Represents:
- Strong buyer dominance

---

## Second Candle
Bearish candle

Should:
- Open higher
- Reverse downward strongly
- Close below midpoint of bullish candle

---

# Important Rule

The bearish candle does NOT need to fully engulf prior candle body.

That difference separates it from:
# Bearish Engulfing Pattern

# 2. Definition of Fair Value Gap (FVG)

# Fair Value Gap

A Fair Value Gap is:
# A price imbalance created by strong displacement

It forms when:
- Price moves aggressively
- One side dominates order flow
- Price skips trading efficiently

---

# Simple Logic

Aggressive move →
Imbalance created →
Market later revisits imbalance →
Efficiency restored

---

# 3. Basic FVG Structure

# Bullish FVG

Candle 1 High
        ↓

      GAP

Candle 3 Low
        ↑

---

# Bearish FVG

Candle 1 Low
       ↑

      GAP

Candle 3 High
       ↓

---

# Important Rule

FVG usually forms:
# Between candle 1 and candle 3

The middle candle is:
# Displacement candle

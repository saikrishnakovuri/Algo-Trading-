# 2. Definition of Order Block

# Order Block

An order block is:
# The final bullish or bearish candle before a strong impulsive move

It represents:
- Institutional accumulation
OR
- Institutional distribution

---

# Basic Logic

Institutions cannot:
- Enter huge positions instantly

So they:
- Build positions gradually
- Leave footprints in price action

These footprints become:
# Order blocks

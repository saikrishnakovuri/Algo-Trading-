# Triple Bottom Pattern — Complete Bullish Reversal Price Action Guide

---

# 1. Introduction

The Triple Bottom Pattern is a powerful bullish reversal structure in technical analysis and price action trading.

It forms after:
- A strong bearish trend
- Multiple failed breakdown attempts
- Strong support defense

The pattern signals:
- Seller exhaustion
- Strong demand zone
- High probability bullish reversal

The Triple Bottom is widely used in:
- Stocks
- Forex
- Crypto
- Futures
- Options
- Indices (NIFTY/BANKNIFTY)

It is considered:
# A stronger confirmation bullish reversal pattern than Double Bottom because support holds multiple times.

---

# 2. Structure of the Pattern

The pattern consists of:

1. First Bottom
2. Second Bottom
3. Third Bottom
4. Neckline
5. Bullish Breakout

---

# Visual Structure

--------------------------------
               Neckline

        \      /  \      /  \
         \    /    \    /    \
          \  /      \  /      \
           \/        \/        \/
        Bottom1   Bottom2   Bottom3

Eventually:
- Neckline breaks upward
- Bullish reversal begins

---

# 3. Core Psychology

The Triple Bottom represents:
- Repeated bearish failure
- Strong institutional support
- Gradual buyer dominance

---

# First Bottom

Sellers still control market.

Strong bearish momentum exists.

---

# Second Bottom

Sellers attempt breakdown again.

BUT:
- Support holds
- Momentum weakens slightly

---

# Third Bottom

Final breakdown attempt fails.

This is critical.

It signals:
# Seller exhaustion

Institutions continue accumulating.

Eventually:
- Buyers gain full control
- Neckline breaks upward
- Bullish expansion begins

---

# 4. Why the Pattern Works

The pattern works because:
- Support absorbs selling repeatedly
- Breakdown traders get trapped multiple times
- Institutions accumulate heavily near lows

Each failed breakdown:
- Weakens sellers psychologically
- Strengthens buyers emotionally

The neckline becomes:
# Major breakout resistance

When neckline breaks:
- Short covering begins
- Momentum buyers enter
- Bullish momentum accelerates

---

# 5. Conditions for a Valid Triple Bottom

# A. Prior Downtrend Required

Pattern must form after:
- Strong bearish trend

Without downtrend:
- Pattern reliability decreases

---

# B. Three Clear Bottoms

All three lows should:
- Form near same support zone
- Show repeated rejection

Perfect equality NOT required.

---

# C. Clear Bounces Between Bottoms

Each bounce should:
- Create identifiable neckline resistance
- Separate bottoms clearly

Weak bounces =
Weak pattern

---

# D. Valid Neckline

Neckline forms at:
- Highest swing highs between bottoms

Acts as:
- Major breakout resistance

---

# E. Volume Behavior

Ideal behavior:

## First Bottom
Strong bearish volume

## Second Bottom
Reduced bearish participation

## Third Bottom
Weak selling momentum

## Neckline Breakout
Strong bullish volume expansion

# 8. Entry Strategies

# Strategy 1 — Neckline Breakout Entry

# Bullish Entry

Enter when:
- Candle closes above neckline

Requirements:
- Strong bullish candle
- Volume expansion

---

# Ideal Breakout Candle

- Large bullish body
- Strong close near highs
- Small upper wick

Avoid:
- Weak breakout candles
- Low volume breakouts

---

# Stop Loss

Place below:
- Third bottom
OR
- Breakout retest zone

---

# Target

Measured Move Technique:

Target =
Distance from bottoms to neckline projected upward

---

# Example

Bottom:
21,700

Neckline:
22,000

Difference:
300 points

Breakout:
22,000

Target:
22,300
